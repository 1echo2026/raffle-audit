# 中奖名单审核工具(进阶 / 巅峰奖池)

纯静态网页:上传 4 个 Excel,浏览器本地完成中奖资格审核并导出结果。**所有计算均在本地浏览器完成,文件不会上传到任何服务器**,可免费部署到 GitHub Pages。

## 使用方法

### 在线使用(GitHub Pages)

部署后直接打开 `https://<你的用户名>.github.io/<仓库名>/` 即可。

### 本地使用

双击 `index.html` 即可打开;或启动一个静态服务器:

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

## 需要上传的 4 个文件

| 文件 | 说明 |
|---|---|
| 强基订单池(原始 .xlsx) | 订单导出,表头含"账号ID/订单ID"等 |
| 升学订单池(原始 .xlsx) | 同上 |
| 进阶奖池问卷(.xlsx) | 取"表单填写"表,表头含"用户昵称/用户头像/所中奖项/提交时间/基地/真实姓名/出单手机号" |
| 巅峰奖池问卷(.xlsx) | 同上 |

- 只需问卷的"表单填写"表(基地/姓名/出单手机号等审核所需信息都在表单里),不需要"发放情况(中奖名单)"表;若文件里只有发放表会被忽略并在日志中提示。
- 网页按**文件内容**自动识别类型,文件名任意;识别后也可手动调整槽位。

## 审核规则

1. **有效订单**:订单归属渠道以前缀 `grow_xcg_zhuanjs_xiaoshou` 开头,且订单金额 ≥ 999 元(均可在页面调整)。
2. **信息直接来自问卷表单**:"表单填写"表直接提供基地/姓名/出单手机号,不再依赖"发放情况(中奖名单)"表与头像 URL 匹配。
3. **加密手机号匹配**:问卷全号按"前 3 位 **** 后 4 位"掩码后匹配订单池联系方式。
4. **一手机号一单**:同一手机号多次抽奖,只保留提交时间最早的一次。
5. **逐单判池**(核心):以**工号**为人,把其名下所有出单手机号的有效订单按支付时间排序逐笔累计——
   - 单笔订单金额 ≥ 2 万元 → 该订单**直接归巅峰**;
   - 累计跨过 2 万元的那笔订单(**跨线单**)及之后的出单 → **归巅峰**;
   - 未满 2 万元时的订单 → 归进阶。
   - 中奖手机号关联的订单归哪个池,本次抽奖就必须在哪个池,否则无效。

## 审核后的处理工具

- **绿色通道**:无效名单每行点「🟢 绿色通道」→ 生成随机码 → 复制粘贴确认 → 该条直接审核通过转入有效名单,码留作凭证(明细表/导出带"绿色通道"列)。
- **查找**:中奖人员明细表与无效名单上方有查找框,按 姓名/手机号/工号/奖品/金额/原因 等关键词实时过滤并高亮。
- **手动修改转有效**:无效名单每行点「✏️ 修改」→ 修正姓名/出单手机号/基地 → 保存并重新匹配,匹配成功且无异常则自动转入有效名单。
- **审核单量排行**:步骤2勾选"审核单量排行",明细表按工号出单单数从多到少排序,并显示单数与累计金额列。
- **历史记录**:每次「开始审核」自动存档一条,也可手动「保存当前审核结果」;历史记录 Tab 可加载/删除/清空(存本机浏览器 localStorage)。

## 导出(点「⬇ 导出」后勾选导出内容)

1. `强基有效订单池.xlsx` / `升学有效订单池.xlsx` —— 过滤后的有效订单
2. `中奖名单审核结果.xlsx` —— 1 个文件 4 个子表:获奖名单(图片格式)、中奖人员明细表(序号/奖池/基地/姓名/工号/出单手机号/业绩归属时间/累计订单金额)、异常名单(含原因/异常类型)、异常名单沟通话术
3. `单量审核名单.xlsx` —— 按工号汇总:姓名/工号/关联出单手机号/出单单数/累计金额/单笔最高/达2万时间,按出单单数降序
4. `第N期奖品底表.xlsx` —— 奖池/奖项等级/奖品名称/份数(中奖人数)汇总,N 取步骤2"期数"输入值

> 浏览器首次下载多个文件时可能询问"是否允许下载多个文件",请选择允许。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个 **Public** 仓库(如 `winner-list-audit`)。
2. 把本目录所有文件推送到仓库:
   ```bash
   git init
   git add .
   git commit -m "中奖名单审核网页工具"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/winner-list-audit.git
   git push -u origin main
   ```
3. 仓库 **Settings → Pages → Source** 选择 `main` 分支、根目录 `/ (root)`,保存。
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/winner-list-audit/`。

更新代码后重新 `git push` 即可,Pages 会自动更新(可能有 1~2 分钟缓存)。

## 技术说明

- 无后端、无构建步骤,仅 HTML/CSS/原生 JS。
- Excel 解析与导出使用 [SheetJS xlsx-js-style](https://github.com/gitbrent/xlsx-js-style)(已随仓库自托管于 `assets/xlsx.bundle.js`,MIT / Apache-2.0)。
- 核心审核逻辑在 `assets/audit-core.js`,界面与导出在 `assets/app.js`,可单独审计。
- **请勿把任何真实订单/中奖 Excel 上传到公开仓库**,网页只在本地读取它们。
